## 📁 核心模块详解

### 1. Server 层 (`src/server/`)

#### 核心文件

- **server.ts** (2909行, 95KB) - 主服务器，定义所有 HTTP API
  - 基于 Hono 框架
  - 支持 RESTful API
  - Server-Sent Events (SSE) 用于实时推送
  - WebSocket 支持（计划中）
  - OpenAPI 规范自动生成

**全局管理**

#### SessionProcessor (`session/processor.ts`)

会话处理器，负责：

- 与 AI 提供商交互
- 流式处理 AI 响应
- 工具调用编排
- Token 统计
- 错误处理和重试

**核心流程**

```typescript
async function processMessage(sessionID, messageID) {
  // 1. 准备上下文
  const messages = await prepareMessages(sessionID)
  const tools = await prepareTools(agent)

  // 2. 调用 AI
  const stream = await provider.chat({
    messages,
    tools,
    model,
    ...options,
  })

  // 3. 流式处理
  for await (const chunk of stream) {
    if (chunk.type === "text") {
      await updateMessagePart(textPart, chunk.delta)
    }
    if (chunk.type === "tool-call") {
      await executeool(chunk.toolCall)
    }
  }

  // 4. 更新统计
  await updateUsage(sessionID, usage)
}
```

## 🔄 请求处理流程

### 完整的用户消息处理流程

```
1. 用户发送消息
   POST /session/{id}/message
   ↓
2. 服务器接收请求
   Server.app.post('/session/:id/message', ...)
   ↓
3. 创建消息记录
   MessageV2.create({ role: 'user', content: '...' })
   ↓
4. 启动会话处理器
   SessionProcessor.process(sessionID, messageID)
   ↓
5. 准备上下文
   ├─ 加载历史消息
   ├─ 加载 Agent 配置
   ├─ 准备工具列表
   └─ 构建系统提示词
   ↓
6. 调用 AI 提供商
   Provider.chat({ messages, tools, ... })
   ↓
7. 流式处理响应
   for await (chunk of stream) {
     if (chunk.type === 'text-delta') {
       ├─ 更新消息部分
       └─ 通过 SSE 推送给客户端
     }
     if (chunk.type === 'tool-call') {
       ├─ 查找工具定义
       ├─ 验证权限
       ├─ 执行工具
       └─ 返回结果
     }
   }
   ↓
8. 更新会话统计
   ├─ 累加 token 使用量
   ├─ 计算成本
   └─ 更新摘要
   ↓
9. 持久化
   ├─ 保存消息
   ├─ 保存会话
   └─ 触发事件
   ↓
10. 返回响应
    { messageID, sessionID, ... }
```

## 🔐 权限系统 (`src/permission/`)

### 权限模型

OpenCode 实现了细粒度的权限控制：

```typescript
namespace Permission {
  export type Ruleset = {
    // 文件系统权限
    filesystem?: {
      read?: PathPattern[]
      write?: PathPattern[]
      execute?: PathPattern[]
    }

    // 网络权限
    network?: {
      allow?: DomainPattern[]
      deny?: DomainPattern[]
    }

    // 命令权限
    commands?: {
      allow?: CommandPattern[]
      deny?: CommandPattern[]
      requireApproval?: CommandPattern[]
    }
  }
}
```

**权限检查流程**

```
工具执行前
  ↓
检查权限规则
  ├─ 匹配 allow 规则 → 允许
  ├─ 匹配 deny 规则 → 拒绝
  └─ 匹配 requireApproval → 请求用户确认
  ↓
执行或等待确认
```
