# OpenCode 三大产物构建指南

## 🎯 目标

构建并测试 OpenCode 的三个主要产物：

1. **CLI** - 命令行工具
2. **Desktop** - 桌面应用
3. **Web** - 网页应用

## 📋 前置条件检查

- ✅ Bun 已安装 (`~/.bun/bin/bun`)
- ✅ 依赖已安装 (`bun install` 完成)
- ⏳ 需要检查的：Rust 工具链（Desktop 需要）
- ⏳ 需要检查的：Node.js（可选，部分构建可能需要）

---

## 1️⃣ 构建 CLI（最简单，推荐先做）

### 📦 产物说明

- **最终文件**: 单个可执行文件
- **大小**: 约 50-60 MB
- **支持平台**: Linux, macOS, Windows
- **构建时间**: 约 2-5 分钟

### 🔨 构建步骤

#### 步骤 1: 构建当前平台的 CLI

```bash
# 在项目根目录
cd /Users/desire/Desktop/Code/opencode

# 只构建当前平台 (macOS ARM64)
bun run --cwd packages/opencode script/build.ts --single

# 或者
cd packages/opencode
bun run build --single
```

**参数说明**:

- `--single`: 只构建当前平台（推荐首次构建）
- 不加参数：构建所有平台（需要更长时间）

#### 步骤 2: 查看构建产物

```bash
# 查看构建结果
ls -lh packages/opencode/dist/

# 你应该看到类似：
# opencode-darwin-arm64/
#   └── bin/
#       └── opencode  (可执行文件)
```

#### 步骤 3: 测试运行

```bash
# 测试可执行文件
packages/opencode/dist/opencode-darwin-arm64/bin/opencode --help

# 你会看到修改后的 "opencode1" logo！
```

#### 步骤 4: 构建所有平台（可选）

```bash
# 如果想构建所有平台
cd packages/opencode
bun run build

# 这会构建：
# - Linux (x64, arm64, musl 等)
# - macOS (x64, arm64)
# - Windows (x64)
#
# 构建时间：约 10-20 分钟
```

## 2️⃣ 构建 Web（第二简单）

### 📦 产物说明

OpenCode 有多个 Web 应用：

| 应用       | 路径                | 用途         | 构建命令      |
| ---------- | ------------------- | ------------ | ------------- |
| **官网**   | `packages/web/`     | 营销网站     | `astro build` |
| **Web UI** | `packages/app/`     | Web 应用界面 | `vite build`  |
| **控制台** | `packages/console/` | 管理控制台   | `vite build`  |

我们先构建 **Web UI**（最常用）。

### 🔨 构建 Web UI

#### 步骤 1: 构建

```bash
# 在项目根目录
cd /Users/desire/Desktop/Code/opencode

# 构建 Web UI
cd packages/app
bun run build
```

#### 步骤 2: 查看产物

```bash
# 查看构建输出
ls -lh packages/app/dist/

# 包含：
# - index.html
# - assets/ (JS, CSS)
# - 其他静态资源
```

#### 步骤 3: 本地预览

```bash
# 使用开发服务器预览
cd packages/app
bun run dev

# 打开浏览器访问显示的 URL (通常是 http://localhost:5173)
```

### 🔨 构建官网（可选）

```bash
cd packages/web
bun run build

# 查看产物
ls -lh dist/

# 预览
bun run preview
```

### 🔨 构建控制台（可选）

```bash
cd packages/console/app
bun run build

# 查看产物
ls -lh .output/public/
```

## 3️⃣ 构建 Desktop（最复杂，需要额外依赖）

### 📦 产物说明

- **框架**: Tauri (Rust + Web)
- **最终文件**:
  - macOS: `.dmg` 安装包
  - Windows: `.exe` 安装程序
  - Linux: `.deb`, `.rpm`, `.AppImage`
- **大小**: 约 10-20 MB（比 Electron 小很多）
- **构建时间**: 首次约 10-30 分钟（需要编译 Rust）

### 🔍 检查前置条件

Desktop 应用需要额外的工具：

#### 检查 Rust

```bash
# 检查 Rust 是否安装
rustc --version

# 如果没有安装，运行：
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# 安装后重启终端或运行：
source $HOME/.cargo/env
```

#### 检查 Tauri 依赖（macOS）

```bash
# macOS 需要 Xcode Command Line Tools
xcode-select --install

# 如果已安装会显示：
# xcode-select: error: command line tools are already installed
```

### 🔨 构建步骤

#### 步骤 1: 安装 Tauri CLI (如需要)

```bash
cd packages/desktop

# 检查 Tauri
bun run tauri --version

# 如果报错，可能需要单独安装
cargo install tauri-cli
```

#### 步骤 2: 开发模式测试

```bash
# 先在开发模式测试（更快）
cd packages/desktop
bun run tauri dev

# 这会：
# 1. 启动 Web 开发服务器
# 2. 编译 Rust 代码
# 3. 打开桌面应用窗口
```

#### 步骤 3: 构建生产版本

```bash
# 构建生产版本
cd packages/desktop
bun run tauri build

# 构建过程：
# 1. 编译前端 (Vite)
# 2. 编译 Rust 代码
# 3. 打包应用
# 4. 创建安装包
#
# 首次构建会很慢 (10-30分钟)，因为要编译所有 Rust 依赖
# 后续构建会快很多 (1-5分钟)
```

#### 步骤 4: 查看产物

```bash
# macOS 产物位置
ls -lh packages/desktop/src-tauri/target/release/bundle/

# 你会看到：
# - dmg/           (macOS 安装包)
# - macos/         (应用包)
```

#### 步骤 5: 测试安装包

```bash
# macOS: 双击 .dmg 文件安装
open packages/desktop/src-tauri/target/release/bundle/dmg/*.dmg

# 或直接运行 app bundle
open packages/desktop/src-tauri/target/release/bundle/macos/opencode.app
```

## 🎯 推荐构建顺序

### 新手推荐顺序：

1. **CLI (--single)** ⭐ 最简单，快速见效

   ```bash
   cd packages/opencode
   bun run build --single
   ./dist/opencode-darwin-arm64/bin/opencode --help
   ```


   ```bash
   # 先测试开发模式

   bun run tauri build
   ```

## 🔧 常见问题

### Q1: CLI 构建失败 - "Cannot find module"

**解决方案**:

```bash
# 重新安装依赖
bun install

# 清理后重试
rm -rf packages/opencode/dist
bun run --cwd packages/opencode build --single
```

### Q2: Desktop 构建失败 - "Rust not found"

**解决方案**:

```bash
# 安装 Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source $HOME/.cargo/env
```

### Q3: Web 构建后无法预览

**解决方案**:

```bash
# 确保使用了预览命令
cd packages/app
bun run build
bun run preview

# 或使用开发模式
bun run dev
```

### Q4: 构建太慢

**优化建议**:

- CLI: 使用 `--single` 只构建当前平台
- Desktop: 首次构建后，增量构建会快很多
- 使用 SSD 和足够的 RAM
