# OpenCode 通信机制与知识库详解

## 🌐 问题 1: 通信机制和 SDK

### 架构总览

```
┌─────────────┐                    ┌─────────────┐
│   TUI/CLI   │  ←─── HTTP ───→    │   Server    │
│  (客户端)    │                    │  (Hono)     │
└─────────────┘                    └─────────────┘
      │                                    │
      │ 使用自研 SDK                       │ 使用第三方 SDK
      │ @opencode-ai/sdk                  │ @ai-sdk/* (Vercel AI SDK)
      │                                    │
      └─────────────┐              ┌──────┴──────┐
                    │              │             │
                    ↓              ↓             ↓
              OpenAPI Schema   OpenAI API   Anthropic API
                生成的客户端     Google API    等...
```

### 1.1 客户端 ↔ Server: 自研 SDK + HTTP

**核心技术**:

- **协议**: HTTP/HTTPS
- **SDK**: `@opencode-ai/sdk` (自研)
- **生成方式**: 基于 OpenAPI Schema 自动生成
- **通信模式**: RESTful API + SSE (Server-Sent Events)

#### SDK 实现位置

```
packages/sdk/js/
├── src/
│   ├── client.ts           # SDK 入口
│   └── gen/                # 自动生成的代码
│       ├── client/         # HTTP 客户端
│       ├── types.gen.ts    # 类型定义
│       └── sdk.gen.ts      # SDK 封装
```

#### SDK 使用示例

**TUI 中的使用** (`src/cli/cmd/tui/worker.ts`):

```typescript
import { createOpencodeClient } from "@opencode-ai/sdk/v2"

// 创建客户端
const client = createOpencodeClient({
  baseUrl: "http://localhost:4096", // Server 地址
  headers: {
    "x-opencode-directory": "/path/to/project", // 项目目录
  },
})

// 1. 发送消息 (HTTP POST)
await client.session.message.create({
  sessionID: "session-123",
  role: "user",
  parts: [{ type: "text", text: "Hello" }],
})

// 2. 订阅事件 (SSE)
const events = client.global.event()
for await (const event of events) {
  console.log("Received:", event)
}

// 3. 调用其他 API
const sessions = await client.session.list()
const tools = await client.tool.list()
```

#### HTTP API 端点

Server 端 (`src/server/server.ts`) 提供的 API：

```typescript
// 全局 API
GET  /global/health              # 健康检查
GET  /global/event               # SSE 事件流
POST /global/dispose             # 清理资源

// 会话 API
GET    /session                  # 列出会话
POST   /session                  # 创建会话
GET    /session/:id              # 获取会话
PATCH  /session/:id              # 更新会话
DELETE /session/:id              # 删除会话

// 消息 API
POST   /session/:id/message      # 创建消息
GET    /session/:id/message      # 列出消息
DELETE /session/:id/message/:mid # 删除消息

// 工具 API
GET    /tool                     # 列出工具
GET    /tool/:id                 # 获取工具信息

// LSP API
POST   /lsp/request              # LSP 请求

// MCP API
GET    /mcp/server               # 列出 MCP 服务器
POST   /mcp/server               # 添加 MCP 服务器
```

#### 通信流程示例

```
用户输入消息
    ↓
TUI Component
    ↓
SDK: client.session.message.create()
    ↓
HTTP POST /session/:id/message
    {
      "sessionID": "xxx",
      "role": "user",
      "parts": [{"type": "text", "text": "..."}]
    }
    ↓
Hono Server 接收
    ↓
路由到处理器
    ↓
SessionProcessor.process()
    ↓
HTTP Response (流式)
    ↓
SSE 推送更新
    ↓
SDK 接收事件
    ↓
TUI 更新界面
```

### 1.2 Server ↔ AI Provider: Vercel AI SDK

**核心技术**:

- **SDK**: `@ai-sdk/*` (Vercel AI SDK)
- **支持的 Provider**: OpenAI, Anthropic, Google, Mistral, Cohere, 等 20+ 提供商

#### 依赖包

```json

{
  "dependencies": {
    "@ai-sdk/anthropic": "1.0.19",

    "@ai-sdk/vercel": "1.0.31",
    "ai": "4.0.55"
  }

```

#### Provider 实现

```typescript
// src/provider/provider.ts

import { anthropic } from "@ai-sdk/anthropic"
import { google } from "@ai-sdk/google"
import { openai } from "@ai-sdk/openai"
import { streamText } from "ai"

// 使用 OpenAI
const model = openai("gpt-4")
const stream = streamText({
  model,
  messages: [...],
  tools: {...}

// 使用 Anthropic
const model = anthropic("claude-3-5-sonnet-20241022")

// 使用 Google
const model = google("gemini-2.0-flash-exp")
```

#### 为什么用 Vercel AI SDK？

1. **统一接口**: 支持多个 AI 提供商，接口一致
2. **流式支持**: 原生支持流式响应
3. **工具调用**: 标准化的 function calling
4. **类型安全**: 完整的 TypeScript 类型
5. **社区支持**: 活跃维护，文档完善

## 📚 问题 2: 本地知识库能力

### 当前状态: **没有内置的本地知识库系统**

OpenCode **目前不提供**传统意义上的 RAG (Retrieval-Augmented Generation) 知识库，但提供了一些**替代方案**和**扩展能力**。

### 2.1 当前的"知识"来源

#### ① 代码上下文 (通过 LSP)

```
src/lsp/
├── client.ts           # LSP 客户端
└── servers/            # 支持的 LSP 服务器
    ├── typescript.ts   # TypeScript/JavaScript
    ├── python.ts       # Python
    ├── rust.ts         # Rust
    └── ... (20+ 语言)
```

**能力**:

- 代码补全、跳转定义、查找引用
- 类型信息、文档提示
- 代码诊断（错误、警告）

**示例**:

```typescript
// AI 可以通过 LSP 获取代码信息
const definition = await lsp.request("textDocument/definition", {
  textDocument: { uri: "file:///path/to/file.ts" },
  position: { line: 10, character: 5 },
})
```

#### ② 项目文件 (通过 Tool 系统)

AI 可以通过工具直接访问项目文件：

```typescript
// 内置工具
- read_file              # 读取文件
- list_directory         # 列出目录
- grep_search           # 搜索文件内容
- view_file_outline     # 查看文件大纲
- codebase_search      # 语义搜索（使用 Sourcegraph）
```

#### ③ MCP (Model Context Protocol) 服务器

**MCP 是什么？**

- Anthropic 推出的标准协议
- 允许 AI 连接外部数据源
- OpenCode 原生支持

**已集成的 MCP 服务器**:

```typescript
// src/mcp/servers/
- filesystem          # 文件系统访问
- postgres           # PostgreSQL 数据库
- memory             # 内存存储
- brave-search       # Brave 搜索引擎
- github             # GitHub API
- gitlab             # GitLab API
- google-maps        # 地图数据
- puppeteer          # 网页爬取
- ... (50+ 服务器)
```

**使用示例**:

```bash
# 添加 MCP 服务器
opencode mcp add filesystem --path /path/to/docs

# AI 现在可以访问该目录下的文档
```

### 2.2 如何实现本地知识库？

虽然没有内置，但你可以通过以下方式**自己实现**：

#### 方案 A: 使用 MCP 服务器（推荐）

创建一个自定义 MCP 服务器，连接到你的知识库。

**示例： VectorDB MCP 服务器**

```typescript
// .opencode/mcp/vector-db-server.ts

import { Server } from "@modelcontextprotocol/sdk/server"
import { ChromaClient } from "chromadb" // 或其他向量数据库

const chroma = new ChromaClient()
const collection = await chroma.getOrCreateCollection({
  name: "my_knowledge_base",
})

// 实现 MCP 工具
const server = new Server(
  {
    name: "vector-db",
    version: "1.0.0",
  },
  {
    capabilities: {
      tools: {
        search_knowledge: {
          description: "Search the knowledge base",
          inputSchema: {
            type: "object",
            properties: {
              query: { type: "string" },
              limit: { type: "number", default: 5 },
            },
          },
        },
      },
    },
  },
)

server.setRequestHandler("tools/call", async (request) => {
  if (request.params.name === "search_knowledge") {
    const { query, limit } = request.params.arguments

    // 向量搜索
    const results = await collection.query({
      queryTexts: [query],
      nResults: limit,
    })

    return {
      content: [
        {
          type: "text",
          text: JSON.stringify(results, null, 2),
        },
      ],
    }
  }
})
```

**OpenCode 配置**:

```json
// opencode.json
{
  "mcpServers": {
    "vector-db": {
      "command": "bun",
      "args": ["run", ".opencode/mcp/vector-db-server.ts"]
    }
  }
}
```

#### 方案 B: 创建自定义工具

```typescript
// .opencode/tool/knowledge-base.ts

import { Tool } from "@opencode-ai/tool"
import { z } from "zod"

export const KnowledgeBaseTool = Tool.define("search_knowledge", {
  description: "Search the local knowledge base",
  parameters: z.object({
    query: z.string().describe("Search query"),
    limit: z.number().default(5).describe("Number of results"),
  }),

  async execute(args, ctx) {
    // 1. 向量化查询
    const queryEmbedding = await getEmbedding(args.query)

    // 2. 相似度搜索（使用向量数据库）
    const results = await vectorDB.search({
      vector: queryEmbedding,
      limit: args.limit,
    })

    // 3. 返回结果
    return {
      title: `Found ${results.length} results`,
      output: results.map((r) => `Score: ${r.score}\n${r.content}`).join("\n\n"),
    }
  },
})
```

#### 方案 C: 使用 file-search（OpenAI 原生）

如果使用 OpenAI Provider，可以利用其 Vector Store：

```typescript
// OpenCode 已支持 file-search 工具
const response = await openai.chat({
  model: "gpt-4",
  messages: [...],
  tools: [
    {
      type: "file_search",
      file_search: {
        vectorStoreIds: ["vs_123456"]  // OpenAI Vector Store ID
      }
    }
  ]
})
```

### 2.3 推荐的知识库技术栈

如果你要构建本地知识库，推荐：

| 组件               | 技术选择                           | 原因           |
| ------------------ | ---------------------------------- | -------------- |
| **向量数据库**     | ChromaDB, Qdrant, Weaviate         | 轻量、易集成   |
| **Embedding 模型** | OpenAI text-embedding-3-small, BGE | 质量好、速度快 |
| **集成方式**       | MCP Server                         | 标准化、可复用 |
| **索引内容**       | Markdown 文档、代码注释、Wiki      | 结构化易处理   |

## 🎯 总结

### 问题 1: 通信机制

✅ **TUI ↔ Server**:

- HTTP + SSE
- 自研 SDK (`@opencode-ai/sdk`)
- 基于 OpenAPI 自动生成

✅ **Server ↔ AI Provider**:

- Vercel AI SDK (`@ai-sdk/*`)
- 支持 20+ AI 提供商
- 统一接口、流式支持

### 问题 2: 本地知识库

❌ **没有内置的 RAG 知识库**

✅ **但有替代方案**:

1. LSP 提供代码上下文
2. Tool 系统访问项目文件
3. MCP 连接外部数据源
4. **可自己实现**: 通过 MCP Server 或 Custom Tool

### 实现建议

如果你想为 OpenCode 添加知识库能力：

```
1. 选择向量数据库 (Chroma/Qdrant)

3. 实现搜索工具
4. 在 opencode.json 中配置
5. AI 自动调用知识库
```
