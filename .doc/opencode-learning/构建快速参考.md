## 📝 快速命令参考

### 设置环境（每次新终端需要）

```bash
# 添加 Bun 到 PATH
export PATH="$HOME/.bun/bin:$PATH"

# 永久添加（只需一次）
echo 'export PATH="$HOME/.bun/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
```

### 构建 CLI

```bash
# 当前平台
cd packages/opencode
bun run script/build.ts --single

# 所有平台
bun run script/build.ts

# 测试
./dist/opencode-darwin-arm64/bin/opencode --help
```

### 构建 Web UI

```bash
# App
cd packages/app
bun run build
bun run preview

# Web
cd packages/web
bun run build
bun run preview
```

### 构建 Desktop

```bash
# 开发模式（推荐先测试）
cd packages/desktop
bun run tauri dev

# 生产构建
bun run tauri build
```

## 🔧 故障排除

### "bun: command not found"

```bash
# 使用完整路径
~/.bun/bin/bun <命令>

# 或添加到 PATH
export PATH="$HOME/.bun/bin:$PATH"
```

### 构建失败

```bash
# 清理并重试
rm -rf dist
rm -rf node_modules
bun install
bun run build
```

### 依赖下载慢

```bash
# 跳过某些平台特定的包
bun run build --single --skip-install
```
