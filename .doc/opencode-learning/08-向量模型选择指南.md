## 🔍 向量模型的核心作用

### 1. 语义理解能力

**好的模型**:

```python
query = "如何实现用户登录"
# 能找到这些相关代码：
- "authentication.ts"      # 认证
- "login_handler.py"       # 登录处理
- "session_manager.java"   # 会话管理
```

**差的模型**:

```python
query = "如何实现用户登录"
# 只能找到包含关键词的：
- "login.ts"               # 文件名匹配
- "user_login_form.jsx"    # 精确匹配
# 错过了语义相关但不含关键词的代码
```

---

### 2. 跨语言理解

**场景**: 公司代码库包含多种语言

| 模型类型       | 中文 Query | 英文代码                  | 效果      |
| -------------- | ---------- | ------------------------- | --------- |
| **多语言模型** | "用户认证" | `function authenticate()` | ✅ 能匹配 |
| **英文模型**   | "用户认证" | `function authenticate()` | ❌ 难匹配 |
| **中文模型**   | "用户认证" | `function authenticate()` | ❌ 难匹配 |

---

### 3. 代码特化能力

**通用模型 vs 代码专用模型**

```typescript
// 代码片段
function processPayment(amount: number, currency: string) {
  const fee = calculateTransactionFee(amount)
  return deductFunds(amount + fee)
}
```

**通用模型 (如 all-MiniLM)**:

- Query: "支付处理流程"
- 相似度: 0.65 (中等)
- 原因: 不理解代码结构

**代码专用模型 (如 CodeBERT)**:

- Query: "支付处理流程"
- 相似度: 0.88 (高)
- 原因: 理解函数语义、参数含义

```typescript
    this.model = await pipeline(
      "feature-extraction",
      "Xenova/multilingual-e5-base", // ⭐ 多语言支持
    )
  }

  async embed(text: string) {
    // Query 需要加前缀
    const prefixed = `query: ${text}`

      normalize: true,
    })
    return Array.from(output.data)
  }
}
```

## 📊 性能优化建议

### 1. 混合策略

```typescript
/**
 * 混合搜索：关键词 + 向量
 * 提升准确率 20-30%
 */
export async function hybridSearch(query: string, limit: number = 10) {
  // 1. 向量搜索（语义）
  const vectorResults = await vectorDB.search(query, limit * 2)

  // 2. 关键词搜索（精确）
  const keywordResults = await ripgrepSearch(query, limit * 2)

  // 3. 融合排序（RRF - Reciprocal Rank Fusion）
  const merged = mergeResults(vectorResults, keywordResults)

  return merged.slice(0, limit)
}
```

### 2. 缓存 Embeddings

```typescript
/**
 * 缓存策略：避免重复计算
 */
export class CachedEmbedding {
  private cache = new Map<string, number[]>()

  async embed(text: string): Promise<number[]> {
    // 检查缓存
    if (this.cache.has(text)) {
      return this.cache.get(text)!
    }

    // 计算 embedding
    const vector = await this.model(text, {
      pooling: "mean",
      normalize: true,
    })

    const result = Array.from(vector.data)

    // 存入缓存（限制大小）
    if (this.cache.size < 1000) {
      this.cache.set(text, result)
    }

    return result
  }
}
```

### 3. 分块优化

```typescript
/**
 * 智能分块：提升搜索精度
 */
export function smartChunk(code: string): string[] {
  const chunks: string[] = []

  // 按函数/类分块
  const functions = extractFunctions(code)

  for (const func of functions) {
    // 每个函数单独索引
    chunks.push(func.code)

    // 包含上下文的版本
    if (func.docstring) {
      chunks.push(`${func.docstring}\n\n${func.code}`)
    }
  }

  return chunks
}
```
