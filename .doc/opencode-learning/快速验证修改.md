## 🚀 如何验证修改

### 步骤 1: 添加 Bun 到 PATH（永久解决方案）

在你的 shell 配置文件中添加：

```bash
# 如果使用 zsh (macOS 默认)
echo 'export PATH="$HOME/.bun/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

# 如果使用 bash
echo 'export PATH="$HOME/.bun/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```


## 🔧 如果遇到问题

### 问题 1: "bun: command not found"

**解决方案**: 使用完整路径或添加到 PATH

```bash
# 临时使用
~/.bun/bin/bun dev --help

# 永久解决：添加到 PATH（见步骤 1）
```

### 问题 2: "Module not found"

**解决方案**: 确保在正确的目录并安装了依赖

```bash
# 检查当前目录
pwd
# 应该显示: /Users/desire/Desktop/Code/opencode

# 安装依赖
bun install
```

### 问题 3: 找不到 "./src/index.ts"

**解决方案**: 你在错误的目录

```bash
# 方案 A: 进入正确的子目录
cd packages/opencode
bun run --conditions=browser ./src/index.ts --help

# 方案 B: 在根目录使用 --cwd 参数
bun run --cwd packages/opencode --conditions=browser src/index.ts --help

# 方案 C: 使用预定义的 dev 命令（推荐）
bun dev --help
```
